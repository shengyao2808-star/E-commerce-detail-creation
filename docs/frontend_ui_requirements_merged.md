# 电商商品视觉 AI 生产台：前端 UI 需求合并文档

## 版本说明

该文档融合了项目现有的**第一版 UI 需求**和面向未来的**成熟版 UI 需求**。第一版需求强调“真实对接后端，不假装具备未实现功能”【317408841166591†L8-L15】、只保留能够支撑基本流程的 5 个入口【317408841166591†L44-L50】并明确了后端目前仅提供的 8 个接口【317408841166591†L25-L37】。成熟版需求则在此基础上规划了完整的商品视觉 AI 生产台，扩展为 10 个页面，并补充了合规预检、强规则、批量管理、详情页编辑、导出列表等高级能力【967114315166650†L87-L100】。

本文档通过区分“**当前可用能力**”和“**未来拓展能力**”的方式，将两份需求整合在一起。开发团队可以先按第一版完成最小可用产品，在后端能力逐步补齐后再扩展到成熟版。

## 1. 项目背景

### 1.1 项目定位

项目旨在为电商运营、设计师及商品视觉团队提供一站式 AI 生成工具：完成商品资料输入、生成合规图片和详情页、发起审核和导出等工作。前台核心流程为：

```
商品资料 → 生图需求 → 提示词生成 → 合规预检 → AI 生图 → 结果预览 → 详情页组装 → 导出
```

第一版的目标仅包括商品资料上传与查看、详情页查看、审核提交与审核记录查看、导出发起与导出记录查看【317408841166591†L8-L15】。成熟版则在此基础上扩展出生成提示词、强规则检测、多种图片类型生成、素材库管理、详情页编辑与版本控制、导出列表等完整能力【967114315166650†L87-L100】。

### 1.2 设计原则

1. **真实对接后端，不做伪数据**：第一版要求所有功能必须基于已有接口实现【317408841166591†L17-L23】；未实现接口对应的功能按钮应禁用并显示原因。
2. **前台极简、后台承载复杂配置**：成熟版将规则库、模型管理、提示词模板、审核流转、用户与权限等复杂功能放在后台，仅在前台保留生成入口、结果展示和合规结果【967114315166650†L31-L34】。
3. **强规则前置，审核兜底**：生成前先通过极限词、电商法、平台禁词、类目规则等检测；风险较高时阻断生成，普通提醒则提示用户调整。
4. **分阶段迭代**：先完成基础能力上线，再逐步扩展到成熟版能力。

### 2.2 页面关系

第一版以单条资料驱动串联流程：上传商品资料 → 查看详情页 → 提交审核 → 查看审核记录 → 发起导出【317408841166591†L54-L63】。成熟版则通过工作台串联多个生成任务，并增加素材库和结果管理：

```
首页工作台 ↔ 新建商品资料 → 生图工作台 → 生图任务详情 ↔ 结果预览 → 详情页预览/编辑 ↔ 导出记录
                                  ↘ 素材库 ↙
```

## 4. 页面需求

本节在成熟版功能的基础上，标注当前已实现与未实现的能力，以指导前端开发分阶段完成。

### 4.1 首页工作台

#### 当前能力

第一版中无首页工作台页面。数据概览与快速入口将在成熟版实现。

#### 成熟版规划

1. **页面目标**：展示今日生成量、成功率、待审核数量、导出次数等数据；提供商品主图、详情首屏、卖点图、场景图等快捷入口。
2. **结构**：顶部 Banner、数据概览区、快速入口区、最近任务区、系统状态区和规则提醒区。
3. **交互要点**：点击“新建生成任务”跳转到生图工作台；在任务卡片中展示任务名称、关联商品和进度，点击进入任务详情。

### 4.2 新建商品资料

#### 当前能力

第一版仅支持单条资料上传和查看，不支持列表管理【317408841166591†L67-L71】。

#### 成熟版规划

1. **表单字段**：在第一版 `ProductMaterialDTO` 的基础上增加商品卖点、描述分段、规格参数、Logo/包装图上传等；字段来源与原表保持一致。
2. **素材上传**：支持图片、视频、文档和包装图的批量拖拽上传；展示缩略图、文件大小、数量和格式限制；上传后提供删除、重新上传等操作。
3. **AI 解析**：上传资料后调用 AI 服务提取核心卖点、适用平台、颜色、材质、容量、尺寸等信息并在页面预览；此功能需后端支持。
4. **资料完整度**：在保存前检查必填项、素材项和平台适配信息完成情况。
5. **底部操作**：提供保存草稿、提交保存和取消等操作，按接口支持的阶段控制按钮状态。

### 4.3 生图工作台

#### 当前能力

第一版没有生图工作台，AI 生成相关入口仅在详情页中显示禁用态。

#### 成熟版规划

这是前台最核心的生成页面，主要模块包括：

1. **商品选择**：展示当前商品缩略图、名称及 ID，支持切换或跳转商品详情页。
2. **图片类型与平台选择**：根据生成需求选择主图、场景图、卖点图、活动海报等，选择天猫、京东、抖音等目标平台，自动适配尺寸和禁词模板。
3. **比例与风格选择**：提供 1:1、4:5、3:4、16:9 等比例及多种视觉风格模板；用户可查看风格缩略图和描述。
4. **需求输入与负面提示词**：用户通过自然语言描述想要的画面，系统自动生成提示词并支持手动修改；另外填写“不希望出现”的元素，生成负面提示词。
5. **提示词预览与合规预检**：在生成前展示主体、场景、元素、风格等提示词，调用合规服务检测是否存在极限词、虚假宣传、医疗敏感词或平台禁词，给予风险等级提示。
6. **参考素材与生成参数**：选择参考图辅助生成，显示当前模型、生成数量、分辨率等参数；提供高级参数入口供管理员调整。
7. **生成操作**：点击生成按钮后创建生成任务，并在按钮中显示加载状态；生成失败时显示原因。

### 4.4 生图任务详情

#### 当前能力

第一版无生成任务功能。

#### 成熟版规划

1. **任务基础信息**：显示任务编号、状态、进度、当前步骤、创建时间、使用模型及版本等；支持取消任务和重新生成。
2. **生成进度**：展示需求解析、提示词优化、合规预检、图像生成、导出等步骤的状态和完成时间。
3. **生成结果**：实时呈现生成的图片列表，显示每张图片的状态和预计完成时间；支持点击查看大图。
4. **日志与合规**：提供实时日志查看功能，展示各阶段的输出和错误信息；合规状态显示内容合规、商标检测、敏感信息检测、素材版权检测等结果。
5. **任务操作**：支持重新生成、取消任务、导出结果，按钮状态根据任务当前状态和接口支持进行控制。

### 4.5 商品资料列表

#### 当前能力

第一版不提供列表页【317408841166591†L67-L71】。

#### 成熟版规划

1. **列表功能**：展示商品缩略图、名称、SKU、品牌、类目、素材数量、状态和更新时间；支持分页、搜索、筛选和排序。
2. **批量导入与模板下载**：提供批量导入功能和模板下载，上传结果反馈。
3. **资料完整度提醒**：通过提醒卡片提示缺少主图、规格信息或卖点信息；提供资料补全引导。
4. **单条操作**：支持查看详情、进入生成、编辑、删除、复制等操作；依据后端接口控制按钮是否启用。

### 4.6 商品资料详情

#### 当前能力

第一版支持查看单条商品资料，但无版本记录、关联任务和编辑功能。

#### 成熟版规划

1. **头部信息**：展示商品图片、名称、品牌、SKU、分类及资料状态；提供面包屑导航。
2. **标签页结构**：分为基础信息、素材清单、版本记录和关联任务四个标签页。
3. **素材预览**：展示图片、视频和文档素材及审核状态；可查看大图、下载文档。
4. **资料状态与完成度**：显示必填信息和素材完成情况，提供完善资料入口。
5. **快捷操作**：可跳转到生图工作台，编辑资料或复制资料；按钮启用根据接口可用性决定。

### 4.7 素材库

#### 当前能力

第一版没有素材库功能。

#### 成熟版规划

1. **分类管理**：按商品原图、AI 生成图、场景图、Logo、文档等分类；可新增自定义标签。
2. **筛选与搜索**：支持名称、标签、类型、类目和时间筛选；支持全局搜索。
3. **上传与批量操作**：支持拖拽上传、批量上传；提供批量下载、删除、打标签、移动分类、设为参考图等功能。
4. **素材详情**：侧栏显示素材名称、尺寸、大小、格式、来源、上传者、所属商品及标签；可编辑标签。

### 4.8 结果预览

#### 当前能力

第一版无生成结果页面。

#### 成熟版规划

1. **任务选择与筛选**：选择某次生成任务并按状态、图片类型、生成时间筛选结果；支持切换宫格视图。
2. **批量操作**: 支持批量导出、下载、重新生成和精选；显示已选数量和结果统计信息（如合规通过率、精选率）。
3. **结果宫格与详情**：宫格展示缩略图、类型标签、合规状态和生成时间；详情面板展示图片评分、提示词、参数信息及加入详情页等操作。

### 4.9 详情页预览 / 编辑

#### 当前能力

第一版仅能查看单条详情页，无法编辑、保存或发布版本。

#### 成熟版规划

1. **版本管理**：支持草稿与发布版本的切换、保存和发布；展示版本状态。
2. **模块化编辑**：提供首屏图、核心卖点、使用场景、参数说明、FAQ、售后保障等模块；支持添加模块、拖拽排序、启用/禁用模块。
3. **画布预览**：提供移动端、桌面端和长图预览；支持缩放、全屏查看和模块定位。
4. **右侧设置面板**：配置标题、描述、背景风格、图片替换等；支持保存草稿和发布版本。

### 4.10 导出记录

#### 当前能力

第一版只能发起导出并查看单条导出记录；不支持列表、下载和删除。

#### 成熟版规划

1. **导出统计与筛选**：统计今日导出数量、成功率、待处理数量和存储占用；提供任务名称、来源任务、导出格式、状态和日期筛选。
2. **新建导出**：创建导出任务时选择导出内容、格式、尺寸和目标平台。
3. **导出列表与详情**：显示导出任务名称、编号、来源任务、格式、文件大小、状态和时间；侧栏查看导出内容、图片数量、分辨率、色彩模式等信息。
4. **下载与重导**：提供文件下载、重新导出、删除记录等操作；显示失败原因和错误码。功能启用依赖后端接口实现。

## 5. 全局规范

### 5.1 状态与空态

所有页面必须支持加载中、成功、空数据、接口缺失、功能待接入和调用失败等状态【317408841166591†L92-L99】。未实现的功能按钮应禁用并提示“当前接口未实现，待后端补齐”或“待接入本地 AI 服务”。

### 5.2 错误态与风险提示

常见错误包括接口不存在、已存在但不可用、后端返回失败、参数校验失败和网络异常。对于风险提示，应按风险等级使用黄色（低风险提醒，不阻断生成）、橙色（中风险需修改）和红色（高风险禁止生成）。

### 5.3 API 对照表

#### 5.3.1 当前已实现接口

第一版可用的接口包括上传商品资料、查看单条资料、查看单条详情页、提交审核、查询审核记录、发起导出和查看单条导出【317408841166591†L25-L37】。

#### 5.3.2 当前存在但不可用的接口

`POST /api/v1/detail/generate` 存在但因 `AIUtil` 未实现而不可用。前端需要保留入口但禁用，并提示待接入本地 AI 服务。

#### 5.3.3 缺失接口与成熟版依赖

成熟版规划新增接口包括商品资料列表、更新、删除；提示词理解、生成、优化和合规改写；合规检测与合规重写；生成任务创建与控制；结果收藏与保存；素材库管理；详情页创建、更新和发布；导出列表、下载和删除等。具体路径和方法可在成熟版需求文档中详细列出。

## 6. UI 风格与组件

前端应采用“简洁、轻科技、企业级”的设计风格，使用科技蓝为主色、青绿色为辅助色，并辅以橙色、红色、绿色表示警告、危险和成功状态。组件应采用大圆角卡片和轻阴影，表格保持适中密度，不使用过度炫酷动效。风格参考 Canva、Figma 等产品，确保留白充足、结构清晰，强调状态反馈。

建议将 UI 组件拆分为全局组件、商品组件、生成组件、任务组件、素材组件、结果组件、详情页组件和导出组件，具体拆分请参考成熟版需求文档。

## 7. 开发优先级与迭代建议

根据当前后端能力，建议分阶段实现：

1. **P0 – 最小可用产品**：完成商品资料上传与查看、详情页查看、审核提交与查询、导出发起与单条记录查看；其他功能入口保留但禁用。
2. **P1 – 核心生成能力**：补齐商品资料列表与编辑接口、合规检测与提示词生成接口后，开发新建商品资料、生图工作台、生成任务详情、结果预览等核心页面。
3. **P2 – 详情页和素材管理**：补齐详情页保存、版本管理、素材库管理等接口后，开发详情页编辑、素材库页面及导出列表。
4. **P3 – 高级能力**：实现批量生成、图生图、局部重绘、高清放大、详情页自动组装、A/B 测试、团队协作、成本统计等高级功能。

## 8. 结论

通过合并第一版和成熟版需求，项目团队能够同时掌握当前可交付的最小产品和未来扩展方向。请在开发过程中遵循“真实后端驱动”的原则，不伪造接口和数据，按阶段迭代，不断完善业务能力。
