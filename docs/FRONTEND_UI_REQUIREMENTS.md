# 电商详情 AI 工作台 - 前端 UI 需求说明

> 版本：v1.3  
> 日期：2026-05-25  
> 范围：前端 UI 与后端真实 API 接入说明

## 1. 当前状态

P0 UI/API 已基本打通，但项目仍有明确缺口，不能写成生产可用。

| 页面 | 路由 | 当前状态 | 说明 |
|---|---|---|---|
| 商品资料列表 | `/materials` | 部分实现 | 列表、筛选、基础操作已接入 |
| 商品资料详情 | `/materials/:id` | 已打通 | 真实详情查询可用 |
| 详情页编辑器 | `/details/:id` | 已打通 | 基础编辑、保存、AI 入口提示已接入 |
| 合规审查页 | `/details/:id/review` | 已打通 | 风险检测、风险结果展示、审核提交已接入 |
| 审核中心 | `/audit` | 部分实现 | 基础记录可读，完整流转仍需补齐 |
| 导出记录页 | `/exports` | 已打通 | 导出列表、下载路径、删除、重新导出已接入 |

## 2. 必须满足的 UI 规则

1. AI 相关入口统一显示“已接入本地AI服务，需配置后可用”。
2. 不得用假数据冒充风险结果、导出记录或审核结果。
3. 不得把未实现接口伪装成可用功能。
4. PDF、CMS、OCR 等未实现能力必须明确提示，不可静默降级成假结果。
5. 移动端需要可读、可操作；列表可转卡片或横向滚动，不得挤压溢出。

## 4. AI 文案约定

- AI 入口、按钮、空态文案统一使用“已接入本地AI服务，需配置后可用”。
- 这里的 AI relay 指 OpenAI-compatible relay，不是内置免费模型。
- 当前文档不允许再写“真实 OpenAI 已实现”之类的表述。

## 5. 当前验收口径

- P0 UI/API 基本打通。
- 已接入功能按真实接口展示，不冒充生产闭环。
- 未实现能力必须明确标注，不得用实现中功能冒充完成。
- 当前状态仍不等于生产可用。
