# 电商详情 AI 工作台 - 前端 UI 需求（P2 后）

> 版本：v1.4  
> 更新日期：2026-05-26  
> 范围：前端页面行为与当前后端 API 实际能力对齐

## 1. 当前目标与边界

本阶段目标是“真实 API 对接 + 真实状态呈现”，不是“全链路 AI 生产可用”。

- 必须基于真实接口返回渲染页面，不用假数据冒充成功结果。
- 对未完成能力（例如任务执行 worker、部分外部集成）必须明确提示“未完成/待配置”。
- P2 已完成的新增能力：研究任务、OCR 任务、设计稿草稿、详情模块顺序持久化。

## 3. P2 关键 API 对接矩阵

## 4. 仍未完成或需谨慎声明的能力

以下能力不能写成“已完成生产可用”：

1. 任务执行 worker 与自动轮询编排：当前已具备任务数据持久化接口，但不代表所有任务都有完整异步执行引擎。
2. AI 生成链路依赖本地/外部配置：未配置时生成与再生成接口会真实失败。
3. 外部系统集成（如 CMS、SSO、多租户隔离等）未在本文件范围内宣称完成。

## 5. UI 文案与交互约束

- 涉及 AI 的入口、空态、按钮提示要使用“已接入本地 AI 服务，需完成配置后可用”这类真实表述。
- 错误态要显示真实失败原因，不做静默降级伪成功。
- 下载、导出、审核、风险结果页面不得使用示例结果替代真实返回。

## 6. 验收口径（P2）

- 研究任务、OCR 任务、设计草稿、模块顺序四类新增接口已完成前后端对接。
- 页面状态与接口真实能力一致，不夸大“已完成”范围。
- 当前结论：P2 对接完成；全链路生产化能力仍有后续工作。
