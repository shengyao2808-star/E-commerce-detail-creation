# 电商详情 AI 工作台

一个面向商品详情生产、合规审查、审核流转与导出的前后端项目。

## 当前状态

- P0 主链路已完成。
- 详情编辑、合规审查、审核提交与导出链路均已接入真实接口。
- AI relay 已接入 OpenAI-compatible relay，需正确配置后可用，不是内置免费模型。

## 已支持

- 商品资料与详情查询
- 详情编辑与审核提交
- 风险检测与风险结果展示
- 导出列表、下载路径、删除、重新导出、发起导出、导出详情查询
- Word / Markdown / JSON / HTML / TXT 导出格式展示
- DOCX Word 资料文本解析

## 明确未实现

- OCR
- PDF 解析
- CMS
- SSO
- 租户隔离
- 完整权限
- 完整审计
- 模特库

## 测试

- 后端：`mvn test` 通过。

本项目文档仅描述当前真实状态，P0 已完成，未实现能力仍按现状保留在“明确未实现”中。
